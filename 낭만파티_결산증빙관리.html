Firebase 보안 규칙 예시와 설정 방법

1. Firebase Console에서 Firestore Database와 Storage를 생성합니다. 2. 웹 앱을 추가한 뒤 설정값을 아래 코드의 firebaseConfig에 붙여넣습니다. 3. 관리자만 접근하도록 Firebase Authentication을 연결한 뒤 아래 규칙의 이메일을 운영자 계정으로 바꾸세요.

Firestore 규칙 예시
allow read, write: if request.auth != null && request.auth.token.email in ['관리자이메일'];

Storage 규칙 예시
allow read, write: if request.auth != null && request.auth.token.email in ['관리자이메일'];
